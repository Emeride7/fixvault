FixVault – Guide rapide

Base de connaissances IT pour techniciens

1
Recherche instantanée

Utilisez la barre de recherche. Syntaxe avancée : cat:Windows, tag:wifi, cmd:ipconfig.

2
Créer une solution

Cliquez sur « + Ajouter ». Le champ Solution supporte le Markdown (listes, liens, code).

3
Commandes & Copie

Les commandes sont affichées avec un bouton « Copy » pour les copier en un clic.

4
Favoris & Offline

Marquez vos solutions fréquentes. Le cache local permet la consultation hors-ligne.

5
Export / Import

Sauvegardez votre base en JSON ou importez une sauvegarde depuis le bouton « Export ».

⬡

Raccourcis : Ctrl+K recherche · Esc ferme les modales · Enter valide les formulaires.
